# Accessibility

These files are read through GitHub and in local editors. Report inaccessible
forms, unclear instructions or barriers in the shared tools through an issue,
with the page, assistive technology and expected result. Contact
[dashynms@pckp.net](mailto:dashynms@pckp.net) if a public report is unsuitable.

We have not completed a formal accessibility conformance audit. Product-specific
reports belong in the affected desktop, mobile, MCP, Core or sensor repository,
which has its own accessibility statement. Use synthetic examples without
credentials or identifiable network details.
