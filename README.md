# DashyNMS repository standards

Shared community guidance, labels and CI/security checks for desktop, mobile,
MCP, Core and sensor-definitions. The public organisation profile is in `profile`.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing a change. Every PR needs
an earlier issue describing the problem or intended result. Follow
[the code of conduct](CODE_OF_CONDUCT.md), report vulnerabilities privately under
[SECURITY.md](SECURITY.md), and use [ACCESSIBILITY.md](ACCESSIBILITY.md) for barriers.

[Repository standards](docs/REPOSITORY-STANDARDS.md) explains the checks, immutable
consumer revisions, copied-helper ownership and label synchronisation. Original
code and documentation use [MIT](LICENSE); see [NOTICES.md](NOTICES.md) for
third-party terms and trademarks.
