# Security policy

Report vulnerabilities privately through the affected repository:

- [Desktop](https://github.com/DashyNMS/desktop/security/advisories/new)
- [Mobile](https://github.com/DashyNMS/mobile/security/advisories/new)
- [MCP](https://github.com/DashyNMS/mcp/security/advisories/new)
- [Core](https://github.com/DashyNMS/core/security/advisories/new)
- [Website](https://github.com/DashyNMS/website/security/advisories/new)
- [Sensor definitions](https://github.com/DashyNMS/sensor-definitions/security/advisories/new)

For shared automation or community files in this repository, email
[dashynms@pckp.net](mailto:dashynms@pckp.net). Use synthetic reproduction data
and exclude credentials and customer network details. We aim to acknowledge
reports within five working days and keep you informed while investigating.

Fixes go into the maintained source and the next applicable release. Existing
published package and catalogue versions remain immutable. Test only systems
you own or have permission to test.
